# 070 — w8: npm 배포 가능 여부

판정만 하고 publish는 하지 않는다. 확인할 것은 넷이다.

1. **이름.** aside-codemode가 레지스트리에 비어 있는지 npm view로 확인한다.
2. **무엇이 들어가는지.** npm pack --dry-run으로 실제 목록을 본다. evidence/, devlog/,
   eval/, test/, .codexclaw/가 들어가면 안 되고, 기계-로컬 codemode.config.json도 안 된다.
3. **실행 진입점.** bin.codemode가 bin/codemode.mjs를 가리키고 shebang이 있는지,
   engines.node가 실제 요구와 맞는지(현재 >=18, CI가 18/20/22).
4. **설치 후 동작.** pack한 tarball을 임시 디렉터리에 설치해 codemode --doctor가 도는지.
   저장소 밖에서도 templates를 찾는지가 핵심 — 설치기는 REPO_ROOT 기준으로 템플릿을 읽는다.

판정은 셋 중 하나로 적는다: 지금 가능 / 준비하면 가능(무엇을) / 불가능(왜). 근거 없이
"가능하다"고 쓰지 않는다.
