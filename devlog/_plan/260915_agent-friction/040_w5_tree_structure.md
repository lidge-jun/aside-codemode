# 040 — w5: 트리를 구조로도

## 지금

attach는 접근성 트리를 **통문자열**과 평탄한 ref 맵으로 준다. 계층은 들여쓰기로만 남는다.
그래서 "과목 - 과제명 - 마감일"처럼 묶인 데이터를 뽑으려면 게스트 안에서 줄을 쪼개고,
과목명을 기억하는 상태 머신을 짜고, 정규식을 돌려야 한다. DOM 셀렉터가 없으니 대안도 없다.

## 고칠 것

같은 문자열을 **한 번 파싱해서** 구조를 함께 싣는다. 새 관찰을 만들지 않고 이미 받은
트리에서 계산한다.

    nodes  [{ depth, role, name, ref?, attrs?, line }]

부모는 depth로 안다. ref가 있는 노드의 ref는 기존 맵과 같은 값을 쓴다. 읽지 못한 줄은
버리지 않고 raw로 남겨 누락이 조용히 생기지 않게 한다.

이걸로 LMS 예시는 "depth가 줄어들 때까지 모으기"로 풀린다. 상태 머신이 필요 없다.

## 반례

1. 중첩된 fixture에서 nodes의 depth가 실제 중첩과 맞는다.
2. ref가 있는 노드의 ref가 기존 평탄 맵과 일치한다.
3. 파싱하지 못한 줄이 raw로 남고 그 수가 결과에 보인다.
4. 산 페이지에서 한 번 돌려 실제 트리로 확인한다.
