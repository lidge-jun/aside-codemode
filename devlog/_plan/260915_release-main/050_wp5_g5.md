# 050 — wp5: G5의 경계 (감사 1차 반영본)

G5는 "새 에이전트 세션, 경로 선택 평가, cold/warm 비교"이고 합격은 "정답 유지, native
단일 작업에 불필요한 우회가 없음"이다. 스킬 평가는 native가 맞는 요청을 절반 이상 섞고
모델이 스킬을 **적절히 안 불렀는지**까지 점수화한다.

## 480실행은 G5가 아니다

앞 루프의 480실행은 cold/warm 비교로서 R6의 성능 자료다. 그 워크로드는 스크립트가 경로를
고정해서 돌린 CLI 실행이고, 모델이 경로를 고른 세션이 아니다. 정답 30/30, 3콜 대 1콜,
복구 6~7ms는 유용한 숫자지만 **경로 선택 평가의 대리 지표로 G5 칸에 넣지 않는다.**
스킬 본문에 "언제 배치하지 말라"가 적혀 있는지 확인하는 문자열 검사도 G5가 아니다.

## 그래서 이 단계가 하는 일

기록만 한다. RC 기록의 G5 칸은 **"돌리지 않음"을 유지**하고, 그 옆에 무엇이 있는지와
무엇이 없는지를 적는다.

    있음   cold/warm 480실행 (R6 성능 자료)
    있음   first-look 워크로드의 정답·왕복 수·복구 시간 (경로가 고정된 실행)
    없음   모델이 경로를 고른 새 세션의 선택 평가 — 사람이 설계하고 채점해야 한다

## main과의 관계

G5가 비어 있어도 main 승격은 막지 않는다. **이건 기준의 변경이고 판단 주체는 사용자다.**
앞 루프의 090은 G0~G5 통과를 RC 조건으로 뒀고 100_rc_record.md는 G5 미실행 때문에
NEEDS_HUMAN으로 멈췄다. 2026-09-15에 사용자가 세 기기 배포와 main 릴리즈까지 진행하라고
명시했고, 그 지시가 이 결정의 근거다. 대신 000의 DONE 조건에서 G5를 빼고, release 본문과
RC 기록 양쪽에 "이 게이트는 돌리지 않았다"와 그 사유를 남긴다. R6를 "닫았다"고 쓰지
않는다 — 원문 R6의 완료 증거는 G0~G5 receipt이고 G5가 비어 있다.
