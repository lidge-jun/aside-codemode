## NEW `eval/bench-search.mjs`

CLI:

```
node eval/bench-search.mjs [--repeats 3] [--dir <dir>] [--query NEEDLE-A1] [--self-check] [--json]
```

`--self-check`: build a tiny temp tree (3 dirs × 10 files, one planted `NEEDLE-51X`), run once, assert equality, exit 0/1. Used by tests/CI-adjacent proof. Not a timing claim.

Default (no `--self-check`):

1. If `--dir` omitted (except `--self-check`, which uses a tiny temp tree), create a temp corpus: 20 dirs × 25 files of filler + 5 planted needles (same idea as `eval/make-corpus.mjs`, smaller). Print the dir.
2. Baseline command (locked; argv-only; no shell):
   - **Primary (when `grep` resolves on PATH):** `baseline.kind = "grep-R"` and `baseline.argv = ['grep', '-R', '-n', '--', query, root]`. Rejected alternatives: `find` + per-file `grep`, `rg --files`, a silent Node walk pretending to be find+grep.
   - **Fallback (no `grep` binary):** `baseline.kind = "node-walk"` — recursive `fs` + line scan in this same script. Still record `baseline.argv` as `[process.execPath, 'eval/bench-search.mjs', '--internal-walk', root, query]`. Never label this `grep-R`.
   - Resolve `grep` the same way `src/rg.js` avoids `.cmd` shims: on Windows accept `grep.exe` / `grep` only, not `grep.cmd`. If only a `.cmd` exists, use `node-walk`.
3. After command: `node bin/codemode.mjs --cwd <root> --code 'return await search.content({ path: ".", query: "NEEDLE", fixedStrings: true, max: 1000 })'` with `CODEMODE_ROOTS=<root>`. Record `after.argv` and `after.code`.
4. Equality: sort `{relPath, line, text}` from both sides. Fail the process if sets differ (`equality: false`). Never report a ratio when equality failed.
5. Repeats: default 3. Record each `baselineMs` / `afterMs` as full floats (`performance.now()`), plus `medianBaselineMs` / `medianAfterMs` / `ratio`.
6. Print JSON:

```json
{
  "root": "...",
  "repeats": 3,
  "query": "NEEDLE-51X",
  "options": { "fixedStrings": true, "max": 1000, "noIgnore": false, "hidden": false },
  "baseline": { "kind": "grep-R", "argv": ["grep", "-R", "-n", "--", "NEEDLE-51X", "<root>"] },
  "after": { "argv": ["node", "<abs>/bin/codemode.mjs", "--cwd", "<root>", "--code", "..."] },
  "runs": [{ "baselineMs": 0, "afterMs": 0, "equal": true, "matchCount": 0 }],
  "medianBaselineMs": 0,
  "medianAfterMs": 0,
  "ratio": 0,
  "equality": true,
  "notOperator51x": true,
  "note": "Companion pair. Not the operator 55s/1s folder."
}
```

If `grep` is missing: fall back to a Node walk labeled `baseline.kind = "node-walk"` and still compare equality. Do not label that walk `grep-R` or `find+grep`.

`--json` is the default stdout shape. Human stderr may print one line `equal=true median=…`.
