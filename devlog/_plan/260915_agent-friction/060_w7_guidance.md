# 060 — w7: 안내

설치되는 문서가 위 다섯을 미리 말해 주면 애초에 걸리지 않는다. AGENTS 블록은 짧게, 스킬과
references는 자세히.

| 문서 | 더할 것 |
|---|---|
| AGENTS 템플릿 | 게스트에 모듈 로더가 없다는 한 줄(주입 전역 이름 포함) |
| 스킬 본문 | readText의 두 인자 모양과 결과 필드, search의 query 대 pattern |
| execution-paths | 샌드박스 규칙 한 절 — 동적 임포트 없음, eval 없음, process 없음, 대신 무엇이 있는지 |
| 새 call-shapes 참조 | 자주 틀리는 호출 모양을 표로: search 두 메서드, readText, attach의 nodes, 심볼릭 링크 신호 |

## 반례

렌더된 문서가 각 항목을 담는지 문서 회귀 테스트로 고정한다. G5를 흉내내지 않는다 — 이건
"안내가 실려 있는가"이지 "모델이 따랐는가"가 아니다.
