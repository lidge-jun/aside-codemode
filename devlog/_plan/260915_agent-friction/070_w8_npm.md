# 070 — w8: npm 배포 가능 여부 (감사 반영본)

판정만 하고 publish는 하지 않는다.

1. **이름.** aside-codemode가 레지스트리에 비어 있는지 확인한다.
2. **무엇이 들어가는지.** npm pack --dry-run의 실제 목록을 본다. 금지 목록만 보지 말고
   **들어가는 것 전부**를 읽는다. 지금 files는 bin/과 scripts/를 통째로 넣는데, 거기엔
   추적된 Windows 바이너리 bin/rg.exe(4MB)와 probe-g3·rehearse-install·release-records·
   backup-accounts 같은 개발용 스크립트가 있다. 그것들이 패키지에 있어야 하는지 판단하고
   적는다.
3. **실행 진입점.** bin.codemode → bin/codemode.mjs, shebang, engines.node(>=18, CI 18/20/22).
4. **저장소 밖에서 템플릿을 찾는가.** doctor는 템플릿을 열지 않으므로 그것으로는 증명되지
   않는다. tarball을 임시 디렉터리에 풀고 **plannedFiles()와 install --dry-run**을 그 안에서
   돌려야 REPO_ROOT 기준 템플릿 해석이 증명된다.

판정은 셋 중 하나: 지금 가능 / 준비하면 가능(무엇을) / 불가능(왜).
